DEFORMABLE ATTENTION

Offset Learning Analysis in Deformable Attention

We visualize the feature-space sampling behavior of deformable attention using a trained THuman checkpoint. The offsets are view-specific displacements in the Sapiens feature map, relative to the LBS-aligned projection.

Each row shows how one canonical template point gathers features around its LBS-projected reference location. We sample some points from the initialized template in canonical space, and their corresponding locations in the source view are shown in the reference image and PCA visualization of Sapiens features.

Red ×
LBS-aligned projection of reference point.
Colored dots and arrows
Learned sampling locations and their offsets from the reference point.
Dot transparency
Attention weight: more opaque locations contribute more to feature aggregation.
Cyan ★
Attention-weighted centroid of the sampled locations.

d represents the overall local sampling neighborhood of each reference point. learned is the offset displacement relative to the initialization.
